Text and Fonts

Typography styles can make text clearer and more comfortable to read.

Set a readable type style

The font-family property can list backup fonts in case the first one is unavailable. The line-height property controls the space between lines.

body {
  font-family: Arial, Helvetica, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}

h1 {
  font-size: 2rem;
}

Getting Started with CSS

CSS (Cascading Style Sheets) controls how HTML looks: colors, fonts, spacing, and layout.

Connect a stylesheet

Save your styles in a file ending in .css. Add a link element inside the HTML page's head to connect it.

<link rel="stylesheet" href="style.css">

Then write CSS rules in style.css. A separate stylesheet can be shared by multiple pages.

body {
  color: #222;
  font-family: Arial, sans-serif;
}

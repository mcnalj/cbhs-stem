Colors and Backgrounds

CSS can set the color of text and the background behind an element.

Choose readable colors

Colors can be written as names, hexadecimal values, or other formats. Keep enough contrast between text and its background so the content is easy to read.

body {
  color: #222222;
  background-color: #f4f8fa;
}

.notice {
  background-color: lightyellow;
}

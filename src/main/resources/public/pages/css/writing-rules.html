Writing CSS Rules

A CSS rule selects elements and describes how they should look.

Selector, property, and value

A rule begins with a selector. Inside curly braces, each declaration pairs a property with a value, separated by a colon. End each declaration with a semicolon.

p {
  color: darkgreen;
  font-size: 1.1rem;
}

Here, p is the selector, color and font-size are properties, and their values describe the styles.

A Model HTML Page: planets.html

A complete example combines document setup, navigation, a main heading, and repeated content.

Look for the structure

In the planets example, each planet has its own heading and description. The page also includes a navigation area and a footer. The complete file includes CSS too; HTML describes the content, while CSS controls its appearance.

<main>
  <h1>Planets in Our Solar System</h1>
  <section>
    <h2>Earth</h2>
    <p>Our home planet.</p>
  </section>
</main>

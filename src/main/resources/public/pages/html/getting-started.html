Getting Started with HTML

HTML (HyperText Markup Language) gives a web page its structure.

Write your HTML in a plain-text editor, such as gedit or VS Code.

Your first page

An HTML document starts with a doctype.

Then the entire page is wrapped in an html element.

The head contains page information.

The body contains what page visitors see.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
    <p>My first web page.</p>
  </body>
</html>

Try it in your browser

  1. Save the file with a one-word name and the .html extension, such as first-page.html.
  2. In Chrome, open the saved file with Ctrl + O on Windows or Linux, or Command + O on Mac.

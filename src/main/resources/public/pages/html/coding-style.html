HTML Coding Style

Readable HTML is easier to understand, edit, and debug.

Make the structure easy to see

Put nested elements on their own lines and indent them consistently. Indentation does not usually change how a browser displays the page, but it helps people see which elements belong together.

<main>
  <h1>My Page</h1>
  <p>A short introduction.</p>
</main>

Use lowercase tag names, quote attribute values, and choose names that clearly describe your content.

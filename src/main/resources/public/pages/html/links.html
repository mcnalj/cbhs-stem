Making Links

The anchor element connects your page to another page or website.

Use the a element

Put the destination in the href attribute. The words between the opening and closing tags become the clickable link.

<a href="https://www.nasa.gov/">Visit NASA</a>
<a href="about.html">Read about us</a>

A full web address links to another website. A relative path, such as about.html, can link to another file in your project.

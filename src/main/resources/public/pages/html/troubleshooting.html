HTML Troubleshooting

When a page looks wrong, check one thing at a time and inspect your HTML carefully.

Common things to check

  • Check that tag names are spelled correctly and every opening tag has a matching closing tag.
  • Close nested elements in reverse order: the last element you opened should be the first one you close.
  • Make sure quotation marks around attribute values are paired.
  • Check that file names and paths match exactly, including capitalization.
  • Save your file, then refresh the browser.
<!-- Incorrect: the paragraph closes before strong -->
<p><strong>Important</p></strong>

<!-- Correct: close the last-opened element first -->
<p><strong>Important</strong></p>

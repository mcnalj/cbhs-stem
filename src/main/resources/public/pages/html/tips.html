HTML Tips to Remember

A few simple habits help make pages easier to use and easier to maintain.

Good habits for beginners

  • Use HTML for meaning and structure; use CSS for visual styling.
  • Use one clear h1 for the page's main heading, followed by headings in a sensible order.
  • Add helpful alt text to images that communicate information.
  • Give links descriptive text so people know where they lead.
  • Indent nested elements and check your work in a browser as you go.
<main>
  <h1>Neighborhood Garden</h1>
  <p>We grow vegetables together.</p>
  <img src="garden.jpg" alt="Raised garden beds in spring">
</main>
